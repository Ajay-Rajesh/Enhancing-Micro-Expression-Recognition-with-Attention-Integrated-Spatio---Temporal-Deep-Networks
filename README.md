Micro-Expression 3D CNN FrameworkA comprehensive PyTorch framework for video-based micro-expression recognition using spatial-temporal deep learning models. This repository implements custom datasets, data loaders, training logic, and three distinct network architectures targeting micro-expression classification.🚀 Key Framework Features3D Convolutional Architectures: Spatial-temporal feature learning via a custom 3D CNN, an advanced 3D ResNet (R3D-18), and a custom Squeeze-and-Excitation Model with Channel Attention.Robust Video Pipelines: Dynamic uniform sequence sampling to ensure exact temporal frame lengths alongside fallback frame padding for shorter sequences.Mixed Precision Acceleration: Automatic mixed-precision (AMP) training utilizing torch.amp context managers for up to 2x speedups on modern CUDA hardware.Robust Optimization: Advanced strategies including differential learning rates, automated class-imbalance weight balancing, and early stopping regularization.
